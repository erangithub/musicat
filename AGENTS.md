# Project rules

## No invented abstractions

Never add a new class or function to this codebase. Not in new files, not in existing ones.

- Fixing, implementing, or refactoring existing code is fine, as long as no new class or function appears.
- New classes and functions may be suggested, but only once the design goes through the owner.
- Design decisions — module layout, names, signatures, data structures — belong to the owner.

If a task appears to require a new class or function, stop and propose the design instead of writing it.
